# ShareIt

Учебный проект Яндекс Практикума: сервис, где люди делятся вещами. Можно выложить вещь, найти нужную, забронировать её на время, оставить комментарий после аренды или создать запрос, если нужной вещи пока нет.

Проект состоит из двух сервисов:

- **gateway** (порт 8080) принимает запросы, проверяет входные данные и отправляет валидные запросы на сервер;
- **server** (порт 9090) содержит основную логику и работает с PostgreSQL.

Кто делает запрос, определяется по заголовку `X-Sharer-User-Id`.

## Что умеет

- пользователи: создать, обновить, посмотреть, удалить;
- вещи: добавить, изменить, найти по тексту, оставить комментарий после аренды;
- бронирования: создать, подтвердить или отклонить (это делает владелец), посмотреть список как арендатор или как владелец, с фильтром по состоянию (`ALL`, `CURRENT`, `PAST`, `FUTURE`, `WAITING`, `REJECTED`);
- запросы на вещи: создать запрос, посмотреть свои и чужие.

## Стек технологий

Java 21, Spring Boot 3.3, Spring Data JPA и Hibernate, PostgreSQL, Maven, Docker Compose. Для тестов: JUnit 5, Mockito, MockMvc, H2.

## Как запустить

Собрать проект через Maven (clean -> package) -> docker compose up --build в терминале


После этого API доступно на `http://localhost:8080`

## Тесты

Основная логика приложения server покрыта тестами на 90+%: Мок-тесты контроллеров, тесты сериализации DTO и интеграционные тесты на service-классы с логикой приложения.
Проверка через Maven (clean-verify)
